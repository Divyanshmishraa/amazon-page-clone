# 🛒 Amazon Clone

A frontend **Amazon homepage clone** built using **HTML and CSS**. This project recreates the look and layout of an e-commerce website to practice frontend development, page structure, styling, and responsive design.

> ⚠️ This is a personal learning project and is not affiliated with or endorsed by Amazon.

## 🚀 Live Demo

[View Live Demo](http://127.0.0.1:5500/practice_1.html)

## 📌 Features

- 🛍️ Amazon-inspired homepage design
- 🧭 Navigation bar with search section
- 📦 Product/category sections
- 🖼️ Product and banner images
- 🔗 Navigation links
- 📱 Responsive layout
- 🎨 Styled using CSS
- 🧱 Structured using semantic HTML

## 🛠️ Technologies Used

- **HTML5** – Website structure and content
- **CSS3** – Styling, layout, spacing, and responsiveness
